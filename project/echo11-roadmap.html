02 — CRITICAL DEPENDENCIES TO REFACTOR FIRST

What in the repo blocks a clean wrap — in priority order.

Drawn directly from echo11-frequencies@main. Clear these before any native packaging, or they compound inside Xcode where they're far more expensive to debug.

D1

Domain fragmentation — echo11.space hardcoded everywhere

manifest.json (start_url:"/"), JSON-LD schema URLs, canonical/hreflang tags, sitemap.xml, service-worker scope and GA all assume echo11.space. Shipping under echo11.app with these unchanged breaks PWA scope, deep links and SEO continuity.

FixCentralize one ORIGIN constant, switch to https://echo11.app, set a 301 from .space, bump the SW cache version so no one is pinned to the old origin.
Blocker
D2

Audio lifecycle is browser-coupled

Start/stop/resume, the iOS silent-switch bypass (looped silent element) and Wake Lock live inline in app.js. Inside a WKWebView these don't guarantee background or lock-screen playback — the core promise of a frequencies app.

FixExtract an audioEngine module with clean play/stop/resume hooks so a native AVAudioSession bridge (Capacitor) can own background mode and interruptions.
Blocker
D3

Monolith: app.js 172 KB · index.html 285 KB

Everything embedded in two files. Functional today, but fragile — one bad edit can take down the whole engine, and it's nearly impossible to unit-test the audio path before submission.

FixLight split only: audio-engine.js, state.js, ui.js. Don't gold-plate — just enough seams to test and to bridge native. Use an AI agent for this (§07).
High
D4

/api/ai-analysis.js is an open POST

The Edge Function proxies to Claude Haiku with your ANTHROPIC_API_KEY. It caps prompt length (good) but has no origin check or rate limit — once the key is behind a store app, abuse is billable.

FixAdd an Origin allowlist (echo11.app + the Capacitor scheme), per-IP rate limiting, and keep Cache-Control: no-store. Verify the key is server-only.
High
D5

Expiring media on a third-party CDN

Your own notes flag that the 432 Hz / 528 Hz video backgrounds depend on a Midjourney CDN that "may expire." If they 404 inside a shipped build, you can't hot-fix without a resubmission.

FixSelf-host all video/poster assets in the repo (you already do for stills) before the build is frozen.
High
D6

App Store icon set + manifest icons

manifest.json points at web-app-manifest-512x512.png. Apple needs a 1024×1024 with no alpha and no rounded corners; a transparent source will be rejected at upload.

FixGenerate the full iOS icon set from a flat 1024 master. Confirm the 512 manifest PNG exists and is opaque.
Medium

04 — TECHNICAL STACK · AN HONEST CALL

Capacitor, not React Native. Wrap the working engine — don't rewrite it.

You raised React Native / Expo for speed. For this codebase it's the slower, riskier path: it would mean re-implementing your entire Web Audio synthesis engine in native audio. Capacitor reuses 100% of what already works.

Capacitor (Ionic)

Recommended
Native shell around your existing HTML/JS/Web Audio.
  • +Reuses all of app.js + the audio engine — zero rewrite
  • +Native AVAudioSession, background audio, push, widgets when you want them
  • +One codebase serves PWA and App Store; iterate via web deploys
  • +Realistic to ship inside 30 days, solo
  • –Still needs native config for the audio session (Week 2 work)

React Native / Expo

Not for v1
Full native rewrite of UI and audio.
  • –Rewrites 3,200 lines of working Web Audio in native audio APIs
  • –Throws away the offline PWA you'd still want to keep
  • –Weeks of work + new bug surface — endangers Jun 30
  • +Right call later if the app demands deep native UX (v2+)

Shortcut for the spike: generate the initial package with PWABuilder (point it at echo11.app), then keep its output as a Capacitor project. You get a submittable scaffold in an afternoon and a real native project you can extend for background audio — best of both, no dead end.

05 — INTEGRATION & MODULARITY

One brand, three modules, loaded from echo11.app.

The Vercel-hosted web is the app. The native shell owns device capabilities; the web layer owns content and UI — so brand changes ship instantly without an App Store round-trip.

Native shell · Capacitor
Device only: audio session & background mode, lock-screen controls, splash/icons, deep-link routing, later push & widgets. Thin and stable — rarely resubmitted.
Web core · echo11.app
Everything visible: the frequency engine, UI, onboarding, brand. Served from Vercel; bundled offline copy via the service worker so it works on a plane.
Edge · /api on echo11.app
The one backend: the Claude-powered AI analysis function. Origin-locked to echo11.app. Add new endpoints here as Insights/Book need them.

Brand consistency is structural, not manual: both the app and the marketing site render from the same echo11.app design tokens and components. A type or color change propagates everywhere at once.

08 — RISK REGISTER · BE HONEST

The five things most likely to cost you June 30.

None are reasons not to ship. Each has a mitigation already built into the sprint plan — surfaced here so nothing is a surprise.

iOS background audio in a WebView

Critical
Web Audio can suspend when the app backgrounds or the screen locks. For a frequencies app that's an existential bug — people listen with the phone in their pocket. Your browser silent-switch trick won't carry over by itself.
MitigatedNative AVAudioSession .playback + UIBackgroundModes audio + Media Session bridge — the centerpiece of Week 2, tested on real hardware.

App Store 4.2 — "minimum functionality"

Critical
Apple rejects apps that are thin wrappers of a website. A pure WebView of echo11.app is squarely in that risk zone.
MitigatedNative onboarding, background audio, lock-screen controls and the Claude analysis feature give genuine native value beyond the site.

Health / medical claims (Guideline 5.x)

High
Language like "healing," "natural anesthetic," "immune boost" and "misophonia relief" invites scrutiny in the Health category and can trigger rejection or a demand for evidence.
MitigatedWeek-3 copy pass softens claims to experiential framing; prominent "Not a medical device" disclaimer in-app, not just in legal.

Review queue vs. a hard date

High
First submissions commonly get one round of notes. If you submit in Week 4, a single rejection pushes you past June 30.
MitigatedSubmit end of Week 3; Week 4 is a dedicated review-response buffer, not new build work.

Solo bandwidth + domain migration mid-flight

Medium
One founder, fixed date, while moving the canonical origin from .space to .app — a migration that can break PWA scope, deep links and SEO if rushed late.
MitigatedMigration is Week 1, before native work; scope is frozen to Signal-only; agents (§07) absorb the refactor load.
